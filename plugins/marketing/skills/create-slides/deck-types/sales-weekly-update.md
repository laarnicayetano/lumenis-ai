# Sales weekly update

A short, recurring deck for a weekly field-sales call — the main forum for sharing news and momentum directly with the sales team. This is the most compressed and narrative-driven deck type here: it is not a report, it's a talk track with slides underneath it.

**Constraints:**

- **5 slides max.** If the source material has more than 5 things worth covering, cut or combine — this deck earns its slot on a recurring call by staying short, not by being comprehensive.
- **One spine sentence** — a single line the whole call hangs on, stated up front (e.g. "Two weeks ago we were selling. Today the market is selling for us. Let's not waste it."). Every slide should be evidence for that line, and the line should name the moment honestly — if the team is flagging, say so rather than opening with manufactured energy.
- **Momentum arc, not a list** — order slides so they build (e.g. third-party proof → customer voice → urgency → the close → what's next), with an explicit one-line transition between each beat so the deck reads as one continuous case, not a sequence of updates.

**Per slide, include:**

- **On slide**: the concrete facts (what happened, when, links) — kept minimal, this is what's shown on screen.
- **Talk track**: what the presenter actually says — the framing, the "why this matters," the connective tissue to the spine.
- **Rep action**: the one specific thing a rep should do this week because of this slide (e.g. "send this link to your top 10 accounts today"). Every slide needs one — this is what makes the deck actionable rather than informational.

Output the same plain-markdown deck format as any other deck (see the parent [SKILL.md](../SKILL.md)), but include the talk track and rep action inline per slide (as extra labeled lines, not just speaker notes) since both are core to this deck type, not optional detail.

Tone: energetic but earned — see [core:audience-archetypes](../../../../core/skills/audience-archetypes/SKILL.md)'s Sales/Channel Partner persona. Arms reps to repeat the message forward, so keep language concrete and quotable rather than abstract.
