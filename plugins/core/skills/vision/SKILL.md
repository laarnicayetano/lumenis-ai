# Vision business unit — context

See `vision.md` for positioning, technology platforms, the product
portfolio, and condition categories.

## How to use this

- This is business-unit-level context, not product-level — for messaging
  about a single named product, defer to that product's own context skill
  (`core:product-optilift`, `core:product-optilight`) where one exists.
  Most of the Vision portfolio below doesn't have a dedicated product skill
  yet — don't invent one; ground claims in `vision.md` and flag the gap.
- Ground technology/product claims in `vision.md`; don't invent specs.
- Pair with `brand-context` for company-wide positioning and voice.
- For tone/depth guidance tailored to who you're writing for (KOL,
  ophthalmologist, optometrist, practice owner, patient), see
  [audience-archetypes/vision-archetypes.md](../audience-archetypes/vision-archetypes.md).
- For competitive landscape, see [competitors.md](competitors.md) — this one hasn't
  had a real research pass yet, unlike Aesthetics' version; it says so rather
  than pretending otherwise.
