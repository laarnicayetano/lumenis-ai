# Audience archetypes

A starter set of Lumenis audience personas. Use these to decide tone, technical depth, and what to emphasize before writing anything audience-facing. This is a draft set — edit freely as real audience research comes in.

## How to use this

1. Identify (or ask) which archetype the communication is for. If more than one applies (e.g. a deck with both clinical and business content), say so and adjust section by section rather than picking one tone for the whole piece.
2. Match language, evidence, and pacing to that archetype's profile below.
3. If a request doesn't cleanly match any archetype, ask rather than guessing — the wrong register (too technical for patients, too soft for physicians) actively undermines credibility.

## Archetypes

Lumenis spans two business units — Aesthetics and Vision — and physician/practice archetypes (including KOLs, who present very different data to very different peer audiences depending on business unit) differ enough between them that they're split into their own reference files rather than treated as one generic "doctor," "KOL," or "practice owner."

- [aesthetics-archetypes.md](aesthetics-archetypes.md) — KOL, Physician, Practice Owner, Patient
- [vision-archetypes.md](vision-archetypes.md) — KOL, Ophthalmologist, Optometrist, Practice Owner (Ophthalmologist-owned), Practice Owner (Optometrist-owned), Patient
- [internal-team.md](internal-team.md) — Sales / Channel Partner, Executive Team

Read the relevant file(s) for the request at hand rather than all three — e.g. an Aesthetics KOL deck only needs aesthetics-archetypes.md.
